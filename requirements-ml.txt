# Semantic-cache ML dependencies (AI service [3]) — CPU-only.
#
# WHY A SEPARATE FILE: these are large (torch is ~120 MB even CPU-only) and
# require PyTorch's CPU wheel index. Keeping them out of requirements.txt means
# the rest of the stack installs fast and the AI service still runs without them
# (the semantic cache disables itself — deferred import in ai_service/semcache.py).
#
# INSTALL (all platforms — the extra index provides the CPU torch build):
#   pip install -r requirements-ml.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# WINDOWS GOTCHA: torch unpacks very deeply-nested files and hits the 260-char
# path limit (WinError 206) unless long paths are enabled. One-time, as admin,
# then open a NEW shell:
#   New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
#     -Name LongPathsEnabled -Value 1 -PropertyType DWORD -Force
#
# PINNING POLICY (why not `pip freeze` everything): the project targets
# "Python 3.11+" and the Docker image is python:3.11-slim, but dev machines run
# 3.13. A full freeze from 3.13 pins version-specific transitive wheels
# (e.g. numpy 2.5.x is 3.12+-only) that then CANNOT install on 3.11. So we pin
# only the DIRECT, behavior-defining packages here and let pip resolve the
# numeric substrate (numpy/scipy/scikit-learn) to whatever fits each Python.
# Embedding OUTPUTS are stable across numpy minor versions, so the cache behaves
# identically across 3.11/3.13 — the reproducibility that actually matters.
# Verified installable on CPython 3.11 (container) and 3.13 (dev).
#
# MODEL WEIGHTS ARE NOT PIP-MANAGED: all-MiniLM-L6-v2 is downloaded from
# HuggingFace on first use and cached under ~/.cache/huggingface. For truly
# offline/identical runs, pre-download it once and share that cache, or set
# SEMCACHE_MODEL to a local path and HF_HUB_OFFLINE=1.

# --- direct dependency ---
sentence-transformers==5.6.1

# --- torch (CPU build; comes from the --extra-index-url above) ---
torch==2.13.0

# --- transformers stack (pinned: these define tokenization/model-load behavior) ---
transformers==5.14.1
huggingface-hub==1.24.0
tokenizers==0.22.2
safetensors==0.8.0

# Numeric substrate (numpy, scipy, scikit-learn) and torch's low-level runtime
# deps are intentionally UNPINNED — pip resolves versions compatible with the
# running Python. See PINNING POLICY above.
